# KnowThingAI IT Development Center Website

Static frontend prototype based on the website concepts created in this conversation.

## Run in VS Code

1. Extract the ZIP.
2. Open the `hydrogen-website` folder in VS Code.
3. Open `index.html` in a browser, or install/use the VS Code Live Server extension and choose **Open with Live Server**.
4. Navigate through Home, About Us, Services, Solutions, Our Work, Careers and Contact Us.

## Important
This is a frontend prototype. Forms, careers, project data, authentication, admin dashboard, database and backend APIs are not connected yet.
Replace placeholder contact information before publishing.
