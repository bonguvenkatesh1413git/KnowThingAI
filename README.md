# KnowThingAI IT Development Center — Website

This is the complete static frontend prototype using the logo supplied in the conversation.

## Run in VS Code
1. Extract the ZIP.
2. Open the `knowthingai-clean-site` folder in VS Code.
3. Open `index.html` with a browser, or use the VS Code **Live Server** extension.
4. Click through all pages.

## Pages
Home, About Us, Services, Solutions, Our Work, Careers, Contact Us.

## Logo
`assets/knowthingai-logo.png` is a cleaned transparent version of the supplied logo for the site header.
`assets/original-logo-reference.png` keeps the original uploaded image for reference.

## Note
Contact details and forms are placeholders. This is frontend-only; backend/database/email are not connected.
